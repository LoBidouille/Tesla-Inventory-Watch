# Tesla Inventory Watch

Surveillez l'inventaire Tesla depuis Home Assistant et recevez une notification lorsqu'un nouveau VIN correspondant à vos filtres apparaît.

- Filtres configurables depuis l'interface.
- Intervalle de vérification configurable.
- Notifications optionnelles.
- Détection des nouvelles annonces par VIN.
- Logo intégré à Home Assistant 2026.3+.

Intégration communautaire non officielle ; l'endpoint Tesla utilisé n'est pas une API publique documentée.
